# File SQL fixtures

`file_sql_multiple_groups.parquet.b64` is generated by Apache Arrow/Parquet
56.2.1 in the `file-sql` Rust unit test. It contains three Snappy row groups,
nullable `id` and `name` columns, and dictionary-encoded strings. The native SQL
integration test covers empty projection, both columns, string-only projection,
filters, aggregation and a CSV/Parquet join.

Regenerate with the repository's pinned format library:

```sh
SEEKDB_FILE_SQL_PARQUET_FIXTURE=/tmp/file_sql_multiple_groups.parquet \
  cargo test --manifest-path rust/Cargo.toml -p file-sql \
  snappy_multiple_groups_projection_nulls_and_count
base64 /tmp/file_sql_multiple_groups.parquet \
  > unittest/sql/engine/basic/data/file_sql_multiple_groups.parquet.b64
rm /tmp/file_sql_multiple_groups.parquet
```
